About

How it works

The Aphotic Sequence is a sigil method by Aphotic. This app follows it.

  1. Write the intent out in full. Numbers are written as words. Punctuation is ignored. X and Z are left out.
  2. Every unique letter becomes one line at the angle the template gives it. The template only supplies angles; the sigil is not drawn on it.
  3. The first letter is the core and is drawn longest. Longer means emphasis.
  4. A repeated letter adds a mark to its line (a dot, a circle, a bar or a doubled line). It never adds a second line.
  5. The shape comes by feel and re-drawing. Here that means about 600 attempts per run. Hashtag shapes are thrown out, closed compartments are avoided, and six of the best are shown.

Every run is different. Each result keeps the seed it was made from, so a saved sigil or a shared link brings back exactly the same one.

Nothing you type leaves this device. There is no account, no server and no tracking. A share link carries the intent text inside the link itself, so anyone you send it to can read it.
